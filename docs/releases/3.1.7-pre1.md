# Bannerlator 3.1.7-pre1

Run Windows apps and games on Android — no PC and no root required.

**3.1.7-pre1 brings the full Deck style: a console-style interface made for controllers, now covering every screen, every setting and the in-game menus.** It also adds a Windows components page with **Remove**, recommendations that look at what a game really uses, and it is the first release that reaches 3.1.6 users as a **small update of about 20 MB** instead of the whole app.

- **Deck style, complete:** side tabs and button hints in landscape, a phone layout upright, the full settings editor, game pages and in-game menus — all driven with a controller.
- **Fits every screen:** the console layout now works at the stock and large display sizes, draws 20% smaller, and keeps clear of a camera hole.
- **Windows components in Deck:** recommended and optional components, the full list and the Wine-or-Microsoft DLL choices, for a game or a whole container.
- **Remove components:** an installed component can be taken back out, and what it changed is put back.
- **Smarter recommendations:** from the game's store, its Steam install script and the DLLs it really loads, not from every installer in its folder.

> ✅ **Nothing to set up.** Switch to the Deck style in **Settings › Appearance › Interface Style**; Classic is unchanged and stays the default.

> ⬇️ **This is the first small update.** On 3.1.6 the in-app updater downloads about **20 MB** and rebuilds the new app from the one you have. Older versions, first installs and this page still give the full APK.

# What's New — everything since 3.1.6

## 🎮 The full Deck style

The Deck style is a console-style interface, made to be driven with a controller. It existed as a preview; 3.1.7 makes it complete.

- **Landscape:** main tabs down the left side, a slim title line, and a button-hint bar along the bottom (L1/R1 tabs, A select, B back, X options, Y search). Android's navigation bar stays hidden — also behind pop-ups and sheets — and a swipe from the edge shows it for a moment.
- **Portrait:** a phone layout with tabs along the bottom.
- **Home:** a hero banner for the game you played last (Play, Game page, Settings, Options), shelves and six library views.
- **Game pages** with play time, launches, storage and the full game menu beside them.
- **Settings editor** for every container, every game and the defaults for new containers: Simple, Advanced and Expert levels, search, an *Inherits from* chain (All containers › container › this game), an Unsaved-changes bar, and per-row reset. Every setting the Classic screens have is reachable; the few that still open a Classic screen say so.
- **The Steam (Linux) client** has its own settings page (Linux runtime, FEX, frame generation) and never shows Wine-only options — the Linux client and the Wine side stay separate.
- **First-run setup** for the Deck style appears only on a fresh install.

## 🕹️ In-game Deck menus

In the Deck style a game gets two panels: the **game menu** on the left (Back, or a four-finger tap) and the **quick menu** on the right (the Menu button). X swaps between them.

- **Every page works with a controller:** after L1/R1 the highlight lands on the new page, Right enters it, Up/Down reach every row, and every toggle, slider and button shows the outline. Sliders step with Left/Right, including the ReShade colour sliders, and A opens dropdowns.
- **Per session:** a Wine game shows the Wine tools (Switch window, Live log, Running programs); the Steam (Linux) client gets a Steam page and no Wine tools.
- The game menu now takes about two thirds of the screen, so more of the game stays in view.
- **Controller Test** opened from the quick menu reads the sticks as sticks again.

## 📐 Fits every screen

- **Any display size:** the console layout used to need a screen at least 720 units wide, so phones at the stock or a larger display size got the phone layout even sideways. Landscape now keeps the console layout down to 560 units.
- **20% smaller:** the whole Deck style — screens, pop-ups, sheets and in-game menus — draws 20% smaller than Classic, on top of the interface-size setting.
- **Camera holes:** in landscape the side tabs run under a camera hole on their edge with the buttons kept clear of it, so there is no black or empty strip.
- **Large sizes:** the hero keeps all four buttons in view, the game page keeps its menu, the side tabs fit short screens without scrolling, and the button hints have bigger tap areas.

## 🧩 Windows components, in Deck

A new **Windows components** page in the Deck settings editor, for a game, a container, or the defaults:

- **Recommended for this game** and **Optional**, each with the reason in a few words.
- **Every component**, with search: installed, not installed, and the ones that need the container started.
- **Wine's or Microsoft's DLLs** for Direct3D, DirectSound, DirectMusic, DirectShow, DirectPlay, XAudio and Visual C++ 2010, plus the media codecs.
- Installs show progress on the row and only start when you press Install. Never shown for Linux entries.

## 🗑️ Remove components

Installed components can now be removed — in the Deck page and in Classic (the Browse & install list and the Win Components chips), for a game's container or a container.

- **Every install from now on records what it changed:** the files it placed, the originals it replaced, the folders it made, and the registry values and keys it set. **Remove** puts the originals back, deletes only what the component added, and restores the registry. Anything changed since the install is left alone and reported.
- **Components installed before this release** have no record. A component with a known Windows Installer product (PhysX, Games for Windows LIVE and similar) is removed by its own uninstaller; anything else says it can't be removed yet and offers **Reinstall**, which records what to undo.
- Removing a component that another installed component needs names it first. Removal only ever happens from the confirm.

## 🔎 Smarter component recommendations

Recommendations used to list every installer found in a game's folder — a repack's generic redistributables bundle filled the list with things the game never uses. Now, strongest evidence first:

1. **What the game's store lists:** Steam's shared redistributables, GOG's dependencies, Epic's prerequisite, Amazon's post-install steps. Games you add yourself are matched to their Steam app id (steam_appid.txt, the install script and more).
2. **The game's Steam install script**, with a DirectX setup read by the parts it carries.
3. **The DLLs the game's exe actually loads.**
4. Installers that nothing confirms move to a folded **Also in the game's folder** group.

DiRT Showdown, for example, went from eight suggestions to the DirectX pieces and OpenAL it really uses. XInput is never suggested: the app ships its own for controllers.

## ⬇️ The first small update

3.1.6 added small updates; this is the first release that uses them. On 3.1.6 the updater downloads a patch of about **20 MB** (the full app is about 525 MB), rebuilds the new app from the installed one, checks it is an exact copy of the release and installs it as a normal update. If anything goes wrong it falls back to the full download.

## 🛠️ Fixes

- **Classic, Linux client:** the Steam (Linux) tile and its in-game drawer no longer offer Wine-only actions (ReShade, Task Manager, Active Windows, Wine tools).
- **Deck:** the Steam (Linux) settings no longer say *This game is no longer in your library*; the Deck hero scrolls fully into view when you move up to its buttons; helper text on the Steam page is readable.
- Pop-ups and sheets in landscape Deck no longer bring Android's navigation bar back.

## ⚠️ Known issues

- **Deck style:** new and broadly reworked — please report anything that looks or navigates wrong, with a screenshot.
- **Windows components:** Steam games you added yourself but don't own on Steam can't be looked up on Steam yet, so they rely on the install script and the exe check. GOG and Epic games installed before this release have no saved dependency list.
- **Remove:** components installed before this release can only be removed when they have a Windows Installer product; reinstall them once to make them removable.
