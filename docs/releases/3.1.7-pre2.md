# Bannerlator 3.1.7-pre2

Run Windows apps and games on Android — no PC and no root required.

**3.1.7-pre2 finishes moving every setting into the Deck style — nothing opens a Classic screen any more — and brings the XMB back full screen.** It also adds **Open with → Bannerlator** for any .exe in a file manager, and Wayland games no longer make Android show *pasted from your clipboard* every time they start.

- **Every setting in Deck:** DXVK/VKD3D, the DX wrapper, the X11 driver, Wayland, drives, audio, ReShade, env vars, the Linux runtime and the rest, all edited in place.
- **XMB, full screen:** a library view in the Shelf, full screen with no side tabs, a game's Settings in its own columns, the game row higher and a clearer backdrop.
- **Open with Bannerlator:** run a Windows .exe straight from your file manager, once or from your library.
- **No clipboard notice:** the phone's clipboard is read only when you paste inside a game.
- **Games in place:** Add games, game details, drive C and Change exe open over Deck, not in Classic's Games screen.

> ⬇️ **Small update.** On 3.1.6 or 3.1.7-pre1 the in-app updater downloads about **21 MB** instead of the whole app (about 527 MB). Older versions, first installs and this page give the full APK.

# What's New — since 3.1.7-pre1

## ⚙️ Every setting in the Deck style

3.1.7-pre1 still opened a Classic screen for a few settings. Now every one is edited inside the Deck settings editor, for a game, a container or the defaults:

- **Graphics:** DXVK and VKD3D versions and options, the DX wrapper, the X11 driver, and every Wayland option including the Mali PanVK settings.
- **System:** drives, Wine version, wallpaper and reset, audio latency and the microphone, player slots, XR, the performance overlay, ReShade, services and presets, power and root options, TV mode and the wrappers a game is detected to need.
- **Environment variables** and, for the Steam (Linux) client, the **Linux runtime** cores, folders and component swaps. The Linux client and the Wine side stay separate.
- **Fix:** saving DirectAudio's fine-tune no longer switches the DirectAudio microphone off.

## 🎮 Games, in place

- **Add games**, **My account**, **game details**, **drive C** and **Change exe** open over the Deck screen you are on; none of them drop you into Classic's Games screen.
- The Deck search no longer has an *All games* entry that left the Deck style.

## 🌊 The XMB, full screen

- **XMB** is now one of the Shelf library views, in place of the Wall and Console views.
- It runs **full screen**: no side tabs, title line or button bar — everything is reached inside the XMB. Back (or B) on the first option returns to the view you came from.
- A game's **Settings** opens the XMB's own settings columns instead of leaving the XMB. The Steam (Linux) entry opens its Deck settings page.
- In landscape the **game row sits three quarters up the screen**, the top line (button hints, position, clock) is bigger, and the backdrop behind it is half as blurred.

## 📂 Open with → Bannerlator

Long-press a Windows **.exe** in any file manager and choose **Open with › Bannerlator**:

- Pick the container (or let it remember one with *Use this container next time*).
- **Play from library** when that container already has the game — its own per-game settings apply, nothing is duplicated.
- **Add to library and run** when it doesn't, or **Run once** with just the container's settings and no shortcut.
- With no container yet, it says to create one first.

## 📋 No more clipboard notice

Starting a Wayland game used to read your phone's clipboard straight away, so Android showed *pasted from your clipboard* every time. The game is now only told that text is there; the clipboard is read when you actually paste inside the game. Copying from a game to the phone works as before.

## ⚠️ Known issues

- **Deck style:** new and broadly reworked — please report anything that looks or navigates wrong, with a screenshot.
- Everything listed under 3.1.7-pre1's known issues still applies (component lookups for unowned Steam games, Remove for components installed before 3.1.7).
